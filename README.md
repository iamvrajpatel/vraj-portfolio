# Vraj Patel — AI / Applied AI Engineer

Personal portfolio for Vraj Patel, showcasing production-oriented work in LLMs, RAG, agentic AI, computer vision, and AI automation.

## Development

```bash
npm ci
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

Portfolio content is centralized in `lib/portfolio.ts`. Public portfolio assets, including the resume and project visuals, are stored under `public/assets` and `public/images/projects`.
